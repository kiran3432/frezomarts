# Rider App MVP

Simple rider web client for:

- ride booking
- live trip status updates
- ride detail refresh

## Run

1. Start backend at `http://localhost:4000`.
2. Serve this folder:

```bash
cd /Users/blackgdevil/Documents/New\ project/apps/rider-app
python3 -m http.server 5173
```

3. Open:

`http://localhost:5173`

4. In UI:

- Click `Request OTP`
- Click `Login` (uses `123456` in dev mode)
- Book ride
